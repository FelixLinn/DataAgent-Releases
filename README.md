# DataAgent 内部发行

本仓库用于托管 DataAgent 的内部安装包和更新清单，保持 **Private**。开发代码在独立仓库维护。

## 内部用户

1. 接受仓库邀请，登录自己的 GitHub 账号。
2. 在 Releases 中下载与你的系统和 CPU 架构匹配的安装包，解压整个目录后运行安装入口。
3. 在 DataAgent 的“帮助 → 应用更新”中，用自己的 GitHub 访问令牌授权更新。
4. 后续可检查新版本、下载并重启安装。治理任务运行时可以下载，安装会等待用户在任务结束后重新点击。

首次包含私有更新功能的安装包尚待发布，目前没有可下载的正式版本。请勿把 GitHub 访问令牌提交到本仓库或分享给其他人。

## 维护者

每个正式 Release 包含经对应平台验收的 ZIP 和 `updates.json`。先上传到草稿，检查完整性后再发布为 Latest。客户端不消费草稿或 prerelease。更新包校验失败不会安装，启动失败会尝试恢复旧版和用户状态。

当前是个人账号下的私有仓库：受邀协作者同时具有写权限，因此仅邀请可信的内部人员。未来需要仅下载权限时，可迁移至组织仓库并使用 Read 角色。
